# lom01in7
我的程序项目
lom01in7 机器视觉项目合集

这是一个基于 OpenCV 的机器视觉学习项目。
📂  项目结构

• 最小框选.py：兑换站灯条检测，用最小外接矩形精准框出灯条。

• 颜色分割.py：通过 HSV 颜色过滤提取目标区域。

• 三维坐标.py：solvePnP 三维位姿解算。

• 最小框选效果图.png / 颜色分割效果图.png：运行效果截图。
🛠️  环境依赖
pip install opencv-python numpy
🚀  使用方法
# 灯条检测
python 最小框选.py

# 颜色分割
python 颜色分割.py
